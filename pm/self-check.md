# PM 自查与纪律写作规范

> 来源：2026-09-29 与 DM 协作期间沉淀。**PM 自己必须遵守**（不只要求团队）。
> 组织方式：每条 = **条款 ＋ 配套动作（必须先发生）＋ 理由**（缺一视为不完整，见 §4）。

## 1. 报数三件套（凡对外报出数字）

**条款**：凡报数，须同时给「① 取值口径 ＋ ② 登记点 ＋ ③ 原始出处（文件／轮次）」。
**配套动作**：落笔前先把这三个写出来；缺任一件 ⇒ **视为不完整汇报、可被驳回**。
**理由**：「凑绿」最常见的形态**不是造假，而是换一个更好看的数**（报名义值不报实测值、报平均数不报分布）。⇒ **造假要判动机、顶替只需对口径；动机不可判，口径可对**。附带好处：**驳回时不需要指控任何人**（只说「缺第②项、请补」）。

## 2. 宣告完成须附核验数字

**条款**：凡宣告「已落 X」（plan／SPEC／报告／skill／记忆），须附 `grep -c`（或等价）的输出数字：**先 0 → 写 → 再 1**。
**配套动作（机制级）**：写入脚本**回显本次实际写入的关键子串**；核验**只对该回显串**跑 `grep -c`，**禁止人手重打模式串**。
**附加要求**：报核验数字时须说明**模式串来源**（＝写入时注入的变量／从文件第 N 行读出）；**说不出来源 ⇒ 该数字不算数**。
**理由**：「落盘」与「写到位」是**两个门**：commit 验落盘、`grep` 验写到位，**缺任一个都会静默失败**。手打模式串会错（实测六次同类错中三次败在"重打串"这一步）⇒ 让**写进去的串与拿来核的串物理上是同一个变量**，则不可能不一致。

## 3. 何时必须实核（返工代价判据）

**条款**：**凡「错一次 ＝ 重来一轮」的动作，一律必须实核、无例外**。
**判据**：**返工代价**（可算），**不是「重要／不重要」**（靠感觉）。
**典型举例（非穷举）**：采集票的代码基点；要发布的构建产物；对外报出的数字。
**理由**：重要性判断依赖人的意识；返工代价**当场可答**（问一句「这个错了要重做吗？」），**不需要先有「这很重要」的自觉才能触发**。

## 4. 纪律的写法与准入门槛

**格式（三件，缺一不完整）**：**条款 ＋ 配套动作（必须先发生）＋ 理由**。
**准入门槛（两关，任一答不上 ⇒ 该纪律不成立）**：
- **查来源**：立之前答「它防住的**真实失效实例**是哪一个」：**没有实例的纪律，就是还没被违反过的纪律，按「未实测不得当证据」的对偶 ⇒ 不算数**；
- **查理由**：写之时若**卡在「理由是什么」写不出来** ⇒ 多半说明它**没有真实来源**，应重新想它在防什么。
**理由**：改法会被抄走，**理由才是「为什么不能省」**：下一个人只看到「要用变量核验」会觉得多此一举；看到理由才知道**省掉它的那一刻，人恰恰处在最容易骗过自己的状态（刚写完、正以为自己清楚）**。

## 5. 裁决原则（PM 专用）

| 原则 | 配套动作 | 来源依据 |
|---|---|---|
| **降级／退役／暂缓 ⇒ 必须带升回条件** | 写明「什么条件下恢复」；否则视为**永久豁免**（不允） | 判据 13 退役、走账层降旁证 |
| **判据的假设被实测推翻 ⇒ 改判据**（不是改实现），且**须保住原设计意图** | 例：`truncated == 0` 本意是"防静默截断" ⇒ 改成"无高价值候选被丢"时，仍须**显式登记 ＋ 可查** | 判据 14（截断是常态非异常） |
| **台架结论不得标「实测」** | 涉设备语义（初始态／时间戳／并发／系统命令文本）者只能标「推得」或「待验」；**台架与真机冲突 ⇒ 先怀疑台架** | 台架四例（自死锁／驻留门／文本格式／初始态） |
| **阈值不得为达标而调** | 改须注明「依据 ＝ 实测」；**外推不改判**（外推是推测、不是实测） | 判据 6 两轮口径 |
| **不得用间接证据代替直接证据** | 凡「设备／资源可用」表述，**发出前当场探测并把输出附上** | 第 8 条 (a) |
| **改交付值前须核证据充分性** | 同登记点下有效样本 ≥ `3` **且**须给轮间变异（`evidence_spread`）；**证据标准不因成本低／可逆而降低** | 模板 ⑧ |
