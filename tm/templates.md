# 测试部门（test）模板（TM）

## 测试计划

```markdown
# 测试计划：{功能标题}

| 字段 | 值 |
|---|---|
| 计划编号 | test-plan-{seq}-{feature-key}（与文件名一致） |
| 版本 | v1.0 |
| 关联 SPEC | `docs/pd/spec/{spec-file}` |
| 测试环境 | {设备/环境} |

## 1. 测试目标

{从 SPEC 验收标准推导}

## 2. 测试范围

| 模块 | 测试内容 | SPEC 章节 |
|---|---|---|

## 3. 测试用例

按适用类别列出，无该类别则删除对应小节。

### 3.1 代码审查（XX-CODE）
| 用例ID | 审查项 | 预期结果 | 优先级 |
|---|---|---|---|

### 3.2 逻辑测试（XX-VAL）
| 用例ID | 测试输入 | 预期输出 | 优先级 |
|---|---|---|---|

### 3.3 交互展示（XX-UI）
| 用例ID | 场景 | 预期结果 | 优先级 |
|---|---|---|---|

### 3.4 回归（XX-REG）
| 用例ID | 场景 | 预期结果 | 优先级 |
|---|---|---|---|

### 3.5 边界数值（XX-EDGE）
| 用例ID | 场景 | 预期结果 | 优先级 |
|---|---|---|---|

## 4. 验收标准覆盖

| # | SPEC 验收标准 | 对应用例 |
|---|---|---|

## 5. 测试数据准备

## 6. 通过标准

|---|---|

## 7. 风险

| 风险 | 影响 | 缓解措施 |
|---|---|---|

## 8. te 派发计划

| 批次 | te | 用例数 | 说明 |
|---|---|---|---|
```

## 测试报告

```markdown
# 测试报告：{功能标题}

| 项目 | 内容 |
|---|---|
| 报告编号 | {seq}-{feature-key}-{YYYYMMDD-HHmm}-v{version}（与文件名一致） |
| 关联测试计划 | `docs/test/plan/{plan-file}` |
| 关联 SPEC | `docs/pd/spec/{spec-file}` |
| 关联开发报告 | `docs/dev/report/{report-file}` |
| 测试环境 | {设备状态} |
| 编译闸 | {build result} |

## 1. 执行摘要

| 类别 | 用例数 | 通过 | 失败 | 阻塞 | 未执行 |
|---|---|---|---|---|---|
| **合计** | | | | | |

## 2. 编译闸验证

{构建命令与结果，新增警告情况}

## 3. 逐类别结果

每个执行过的类别一节，无该类别则删除。

### 3.1 {类别名}（XX-CODE）
| 用例ID | 预期 | 实际 | 结果 | 证据 |
|---|---|---|---|---|

**结论**：{一句话}

## 4. 发现问题

### 4.1 阻塞/严重
| 级别 | 描述 | 位置 | 建议 |
|---|---|---|---|

### 4.2 观察项（非阻塞）
| 描述 | 影响 | 建议 |
|---|---|---|

## 5. 运行环境待验证项

## 6. 测试结论

| 维度 | 结论 |
|---|---|

**总体判定**：{通过 / 有条件通过 / 不通过 + 一句话理由}
```

验收标准的用例覆盖见测试计划的「验收标准覆盖」节，报告不重复；验收结果体现在「逐类别结果」与「发现问题」。

## te 派发 prompt 模板

名字固定 `te`，一条消息发起同批全部调用。

```
角色：te，测试执行 agent，只审查验证，禁止修改任何业务代码。只向 TM 汇报。

上下文：
- SPEC：{spec-path}
- 测试计划：{plan-path}
- 开发进度报告：{dev-report-path}

本批次用例（{类别}）：
| 用例ID | 审查项 | 预期结果 |
|---|---|---|
| ... | ... | ... |

手段：Read 源码、grep 静态断言、代码走查（逐条代入输入分析分支输出）。
每条结果必须给出 file:line 或 grep 命中/零匹配作为证据，无证据的结论视为 BLOCKED。

严格按以下格式返回，不要附加其他内容：

## 结论：PASS / FAIL / BLOCKED

| 用例ID | 预期 | 实际 | 结果 | 证据 |
|---|---|---|---|---|

## 发现问题
| 级别 | 描述 | 位置 | 建议 |
|---|---|---|---|
```
